# 文档索引

本目录按任务书第 6 节列出的六类提交物组织。教师下发的任务书与评分标准放在最外层，
其余文档按用途分三类：验收主报告、设计与数据附录、历史记录。

## 提交物对照

| 任务书 §6 要求 | 对应位置 |
| --- | --- |
| 能从干净构建目录编译的工程源码 | 仓库根目录。入口 `CMakeLists.txt`，学生实现在 `student/`，测试与工具在 `tests/`、`tools/` |
| 环境和运行说明 | `README.md`（构建/运行/工具）、`环境依赖.md`（依赖清单与安装方式）、`docs/实验报告.md` 第 2 节（复现步骤与自检结果） |
| 完整标定材料及填写后的配置 | `calib_data/`（21 张棋盘格原图）、`config/camera.yaml`（内参已填、外参平移已填）、`tools/calibrate_intrinsics.cpp`（解算程序）、`云台外参.md`（外参标定方法与现状）、`docs/实验报告.md` 第 3 节 |
| 模型、分类器等离线资源及来源说明 | `models/`、`models/README.md`（来源、输入输出、解码方式、A/B 记录） |
| 测试视频或现场演示材料 | `tests/resources/`（五段实拍 avi，约 133 MB，超出仓库限制未入库，单独提供）、`tests/evidence/`（检测问题取证图）、`docs/figures/`（俯视图与误差曲线） |
| 实验报告与个人答辩材料 | `docs/实验报告.md`、`docs/答辩提纲.md` |

## 验收主报告

**`实验报告.md`** 是本次提交的主文档。它按评分表的七项组织，每项写明做了什么、
为什么这样做、实测数据、还剩什么问题。答辩和现场验收以这份为准。

## 工具脚本索引（`tools/`）

脚本都只读数据、不改工程，用途写在各自文件头。按"想知道什么"分类：

| 想回答的问题 | 脚本 |
| --- | --- |
| ω 抖不抖？改前改后差多少？ | `compare_omega.py`（SSE 曲线 → 对照表 + PNG）、`omega_periodogram.py`（用 90° 点阵周期图从视频里估"真实转速"，避开逐帧差分被噪声吞掉的问题） |
| EKF 的 ω 跟得对不对？ | `gt_omega.py`、`omega_truth.py`（滑窗位置角最小二乘独立估一条参考曲线） |
| 瞄准点准不准？ | `pred_error.py`（`--dump` CSV 里瞄准点 vs 未来实测板心）、`eval_model_fit.py`（模型四块板 vs 实测板贴合度） |
| 转速估计窗口接受了多少、拒了多少？ | `summarize_ev.py`（`TRACK_DEBUG=1` 日志）、`analyze_sse.py`（SSE dump 里的跟踪行为指标） |
| 观测几何本身有没有偏置？ | `parse_poses.py`（`POSE_DEBUG=1`：法向相位 vs 位置相位的系统偏置） |
| 扫参 | `sweep_q.py`（角加速度常量 `SPIN_Q`）、`sweep_sigma_q.sh`（σ_yaw × SPIN_Q 二维） |
| 三组实拍回归一次跑完 | `run_ekf_regression.sh` |
| 抓数据 / 出图 | `run_tool.sh`（起停 `test_camera_system` 抓 SSE，注释里写了为什么不能分两次调用）、`dump_mini.sh`（俯视图 PNG 序列） |
| 没有实车也能联调 | `virtual_serial.sh`（socat 虚拟串口 + 内置模拟电控按 64 字节协议喂帧） |
| 模型 / 标定辅助 | `make_small_ir.py`（改 yolov5 Detect 头网格尺寸）、`calibrate_intrinsics.cpp` |

## 历史记录

`archive/` 存放开发过程中的阶段性分析，按时间排列。这些文档记录了当时怎么想的、
哪些方案被证伪，不作为提交物的一部分，保留是为了回答"为什么最后是这个方案"。
其中 `archive/任务进度备份.md` 是完整的开发日志。

主报告引用了 `archive/` 里几份文档的结论，需要追溯细节时按文件名查找。
