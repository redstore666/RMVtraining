# 旋转目标角速度估计：相位折叠拟合

本文说明 `student/src/RotatingArmorSpinFit.cpp` 的数学与取舍。它是 tracker 里
ω 的唯一来源（`updateYawRateFromPhaseFit`），输出一个标量 ω 与它的标准差 σ，
交给 EKF 原有的经典标量卡尔曼更新（`RotatingArmorEkf::updateYawRate`，H = e₇）。
**EKF 本体没有为这件事做任何改动。**

> 旧的四路证据融合路径（法向 Theil-Sen / 方位角 Theil-Sen / 同帧双板弦向 /
> 原始法向全配对）已于 2026-10-31 整体删除，代码里不再有 `updateYawRateFromWindowLegacy()`
> 与相关开关。§2 记录它为什么必须被替换，作为设计依据保留。

---

## 1. 观测量：板相位

旋转车体上第 k 块板的板心位置由模型给出（`RotatingArmorModel::measurement`）：

```
p = c − R·[cos φ, sin φ],   φ = θ + 2πk/N
```

`c` 是车心，`R` 是半径，`N` 是板数（四板车 N=4），`θ` 是车体转角，`φ` 是**板相位**。
于是从一次观测里可以反解出相位：

```
φ = atan2(c.y − p.y, c.x − p.x)
```

板面法向 yaw 与相位差一个 π（`worldYawToPlatePhase`），也可以作为相位观测，但
实拍法向有固定偏置和 ±20° 抖动，只能低权重参与（见 §4.4）。

关键点：**φ 绕车心转，因此只要车心估计基本正确，φ(t) 的斜率就是 ω。** 这也是
这个方案唯一的外部依赖——车心（state 0/2）与半径（state 8）来自 EKF。

## 2. 旧路径为什么抖：中位数是阶梯函数

四路证据每一路都形如"取若干对样本、算两两斜率、取中位数"。滑窗每前移一帧，
参与配对的那个点集就整体换一次（旧点出窗、新点进窗），中位数因此是一串**阶梯**：
相邻两帧的估计值会突然换一档，而不是连续变化。ω 曲线上的锯齿、以及"锁定后
仍然抖"的现象，直接来自这个结构，调任何参数都治不好。

替换思路很直接：**不要两两配对，把整窗样本一次性联合解一个参数。**

## 3. 折叠相位拟合

### 3.1 模型与折叠

刚体匀速旋转时，板相位随时间线性变化：

```
θ(t) = φ₀ + ω·(t − t̄)        t̄ = 加权平均时刻
```

难点在换板：四块板几何全同，第 k 块板与第 k+1 块板的相位差恰好 2π/N，观测上
无法区分。传统做法是"最近邻续接 + 解缠 + 断链清窗"，每一件都是一类伪值的来源
（续接到别的板就得到假高速）。

这里把不可区分性直接写进模型：**残差按 2π/N 折叠**

```
r(t) = fold( φ(t) − φ₀ − ω(t − t̄), 2π/N )
```

换板带来的 ±2π/N 跳变在折叠下恒等于 0，因此不需要任何续接逻辑。

### 3.2 给定 ω 时 φ₀ 有闭式解

把残差写成 `φᵢ − ω·Δtᵢ − φ₀`，按 2π/N 折叠等价于对 `N·(φᵢ − ω·Δtᵢ)` 取模 2π。
最小化折叠残差的平方和，等价于最大化**相位集中度**

```
C(ω) = | Σ wᵢ·exp( j·N·(φᵢ − ω·Δtᵢ) ) | / Σ wᵢ        ∈ [0, 1]
φ₀   = arg( Σ wᵢ·exp( j·N·(φᵢ − ω·Δtᵢ) ) ) / N
```

于是问题从"两参数非线性拟合"退化成**一维搜索 ω**，φ₀ 是副产品。C 的物理含义
很直白：数据真的像一个刚体在匀速转时 C→1，散成一团时 C→0，可以直接当质量门限用。

数学上这与 `tools/gt_omega.py` 的"4θ 周期图"是同一个量（都是 N 重折叠下的相位
集中度），所以真值工具与生产估计器口径一致，可以逐帧对拍。

### 3.3 搜索与精化

1. 粗网格：`[−max_abs, +max_abs]` 按 0.25 rad/s 取点算 C；
2. 选峰（§4.1）；
3. 在选中峰两侧 ±1.5 个网格步长内做黄金分割，最大化纯 C（先验不参与这一步，
   避免把估计值往先验上拽）；
4. 在最优 ω 上取 φ₀、C、折叠残差 RMS。

C(ω) 在 ω 上是多峰的：主瓣两侧还有 −13 dB 量级的旁瓣，间距约 `2π/(N·T)`
（T=0.45 s、N=4 时 3.5 rad/s）。最优点附近"8 rad/s 与 4.5 rad/s 一样好"是正常
现象，必须显式处理，见 §4.1。

### 3.4 不确定度

最小二乘斜率的经典方差：

```
σ_ω = sqrt( Σw·r² / Σw / Σw·(t−t̄)² ) · sigma_scale
```

下界 `sigma_floor_rad_s` + 放大系数 `sigma_scale`（默认 1.5）是必要的：相邻两帧的
窗口高度重叠，估计值强相关，直接把拟合协方差当独立量测喂进 EKF 会让滤波器过度
自信，ω 反而追着噪声走。

### 3.5 二次精化：变速目标

线性模型对**变速**目标是错的——窗口内 ω 在变时，拟合出的是窗口平均值，正弦素
材的峰谷会被削平。把曲率也当参数：

```
θ(t) = φ₀ + ω·(t−t̄) + ½α·(t−t̄)²
```

此时 ω 恰好是**窗口中心时刻**的瞬时转速。做法是：在全局最优 ω₀/φ₀ 处把残差对
(a, b, c) 做三参数加权最小二乘，取 ω = ω₀ + b。

但匀速目标上 c 与 0 不可区分，硬留二次项只会把方差搬进 ω（实测 std 0.19 → 0.28），
所以用**曲率显著性**门控：`|c|/σ_c > curvature_significance`（默认 2.0）才采纳。

## 4. 四个必须显式处理的工程问题

### 4.1 先验的代价必须有界

选峰需要一个"上一帧的 ω"来打破近似等价的别名峰，否则噪声会让两座峰逐帧轮流
赢，ω 变成方波。

第一版把它写成目标函数里的二次罚（标准 MAP）：

```
score = C − ½·w·((ω − μ)/σ_prior)²
```

结果是**自锁**：8 rad/s 的合成场景里估计一旦偏到 1 rad/s，正确峰被罚
`(8−1)²/(2·1.5²) ≈ 11`，而 C 的上限只有 1 —— 罚项永远赢，估计器再也回不来。

现在用**线性（拉普拉斯）罚**，且只参与"选哪座峰"：

```
选峰打分 = C − penalty·|ω − μ|,     penalty = 0.03 C/(rad/s)
```

代价有界：帧间跳 5 rad/s 只罚 0.15，而"真峰 vs 别名峰"的 C 差通常 0.5~0.9，
真峰永远能翻盘；同时 0.15 已经足够压住噪声造成的峰间抖动。峰内落位仍用纯 C
精化，所以先验不会把数值往 μ 上拽。

### 4.2 相位参考点：两种朴素做法都是错的

`φ = atan2(c − p)` 里的 c 不能随便取，而 φ 的斜率正是被测的 ω，所以参考点自身的
任何运动都会被原样读成转速。三种做法都试过：

| 参考点取法 | 静止目标 | 平移目标 | 结论 |
| --- | --- | --- | --- |
| 每条样本存"采集时刻的 EKF 车心" | 车心在窗口内随机游走 6 cm → 假转速 0.5 rad/s | 常值滞后自动抵消，正确 | ✗ |
| 全窗统一用当前车心 | 正确 | 板心在跑参考点不动 → 假斜率 2.8 rad/s | ✗ |
| 用 EKF 的 vx/vy 把当前车心反推回各帧 | 正确 | v 本身不可信（真值 0.5 m/s 估到 (−0.33, +0.42)）→ 放大误差 | ✗ |

最终做法：**两档参考点各拟一次，取相位集中度 C 高的那个。**

- **A 固定参考点** = 窗口内车心快照的均值。车心的随机游走被整体抹平，φ 序列在
  静止/自转目标上是常数 → 假斜率消失。
- **B 逐帧参考点** = 每帧自己的车心快照。匀速平移带来的常值滞后在 δ = c − p 里
  自动抵消。

这两档是同一个似然的两套解释，用 C 比较即可，不需要任何工况阈值——这比"按速度
大小判断目标动没动"稳健得多（实测平移场景里 EKF 车心 0.45 s 只走 0.13 m，真值
是 0.22 m，位移判据同样会失灵）。

### 4.3 断流与跨度

- 窗口内最后一条样本太旧（`spin_fit_max_gap_s`，默认 0.20 s）说明中间掉帧/被挡/
  换了目标，旧相位与新相位之间可能已经转过好几块板，直接清窗；
- 时间跨度不足 `min_span_s`（0.20 s）时 ω 与 φ₀ 不可分，判无效；
- 样本数不足 `min_samples` 同样判无效。
判无效的那一帧**不更新** ω，由 tracker 的衰减项把 ω 慢慢拉回 0。

### 4.4 法向相位的用法

法向相位与位置相位描述同一个量，但它有固定偏置与 ±20° 抖动。只有它**与同一帧
的位置相位折叠后一致**（差 < `phase_gate_rad`，默认 0.35 rad）时才入拟合，权重
0.30。这样它只在"两路互相印证"时提供额外角度信息，不会单独把解缠带偏。

## 7. 已知限制

1. **变速素材的谷底被削平**。0.45 s 窗口对一条 2.3 s 周期的正弦必然做平均：
   sinspeed 的 ω 中位数比旧路径高约 1 rad/s，谷底停在 2.5~3（旧路径能到 0~1）。
   缩窗到 0.35/0.30 s 能让谷底下去（3.0/2.95），但 redrotate 的 std 会从 0.22
   涨到 0.30/0.41，所以默认取 0.45。若下游更在意变速响应，可单独调小这一路窗口。
2. **云台抖动场景比旧路径敏感**。手持抖动让世界系里的板整体在晃，相位序列里
   确实存在一个转速分量，相位拟合会如实报出来（合成场景 −0.00 → +0.24，仍在
   容差 0.60 内）。旧路径靠法向 Theil-Sen 中位数把它压得更死。
3. **依赖车心与半径**。EKF 的 R 崩坏时（clamp 到下限）绕坏极点算出的相位本身
   就是噪声，所以 R 超出合理区间时直接不估转速。
4. **折叠对称性带来的固有模糊**：八块板几何全同时 ω 只能确定到 `2π/(N·T)` 的
   别名，靠 §4.1 的线性先验在别名峰之间裁决，而不是靠数据本身。
5. **历史残留**：关联循环里还有一条逐帧轨道段量测（`rate_from_tracklet_enabled`，
   用相邻两帧板心绕车心的转角差），它的 σ = max(0.35, σ_θ/dt) 在 166 fps 下约
   10 rad/s，实测等于不接受，不影响 ω 曲线。没有一起删掉，是因为它和这条相位
   拟合无关、删了会改动数值结果，需要重跑一轮实拍对拍才能确认无回归；留作后续
   独立提交。
