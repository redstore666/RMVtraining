| 项 | 内容 |

| 现状规模 | `TrackerConfig` **213 个可调项**、**47 个 bool 开关**、**46 个环境变量** |

## 1. 现象归纳（先不看代码，只看行为）

同一台车、同一段视频（`v4`，`--only-id 3`，741 对相邻观测），相邻帧的位移分布**不是连续的**：

| 区间 | 占比 | 物理含义 |
|---|---|---|
| < 0.05 m | **49.5%** | 与真实切向运动相容（8.4 mm/帧） |
| 0.05–0.20 m | 31.9% | 中间态（换板 + 帧间隙混合） |
| **0.20–0.26 m** | **0.0%** | **空档** |
| 0.26–0.44 m | **17.1%** | 邻板 2R·sin45°≈0.232 / 对面板 2R≈0.328（R 拟合 0.164） |
| > 0.44 m | 1.5% | 跨两块板 |

连续噪声不会在 0.20–0.26 留空档、却在两个几何常数上堆峰 —— 位移里混着**离散的身份跳变**。

按当帧检出板数拆开，法向一致性断崖式分化：

| 帧类型 | 法向差 p50 | >150° 占比 |
|---|---|---|
| 单板帧 | 34° | **0.2%** |
| 多板帧（≥2） | 151° | **51.0%** |

→ **单板路径是好的；一切异常都发生在"同帧有多块同编号板"这个工况。**

## 2. 架构缺陷判定

### 2.1 问题的真身：一个离散隐变量被当成连续量做点估计

系统里存在一个**不可观测的离散变量**：

```
k_i ∈ {0,1,2,3}    第 i 个观测对应车上的哪一块板（板身份）
```

它为什么不可观测：四块板同编号、同尺寸、同圆；检测只给 `target_id`，不给"第几块"。

而当前架构的处理方式是——**每帧用一次 argmin 把它判死**：

```cpp
// RotatingArmorTracker.cpp:2793
if (score < best_distance) { best_distance = score; best_slot = slot; }
```

统计上这一步等价于：把混合似然 `p(z|x) = Σ_j (1/N)·N(z; h_j(x), R)`
**只保留最大分量、其余权重硬置 0**，并且不把"判错的概率"传下去。
一旦判错，位置更新就把 0.23~0.33 m 的假位移当真值吃进状态。

**这不是 bug 多，是把一个估计问题当成了判定问题。**

### 2.2 由此必然产生补丁链

因为 argmin 丢掉了不确定性，每个失败工况都只能靠"再加一条规则/一个权重"去堵：

| 补丁 | 它其实在近似什么 |
|---|---|
| `position_gate_m = 0.60` | 想让错板进不来 —— 但 0.6 m > 板间距 0.44 m，两边都放行 |
| `association_angle_weight_m_per_rad = 0.30`（米/弧度！） | 想用角度否决位置 —— **量纲不成立的临时权** |
| `normal_tiebreak_weight` | 同上，第二个同类权（默认 0，等于承认它没用） |
| `joint_pair_binding` + 4 种整体旋转代价 | 想联合决定两块板 —— 是"多假设"的雏形，但只保留最优一个 |
| `slot_phase_update_enabled` + `slot_phase_min_rate_rad_s` | 想用相位约束身份 —— 只在 |ω|≥1.2 时开 |
| `single_plate_realign_m` / `realign_after_misses` | 判错后把状态拽回来（事后补救） |
| `obs_continuity_gate_m` / `bootstrap_updates` / `nis_gate` | 让判错不要立刻生效（延迟生效） |
| `handoff_sigma_scale`（已标"已废弃"） | 上一代同款补丁的化石 |

**共同点**：全都在用**人手调出来的标量权重**去替代一个**概率**。
这就是"过拟合"的严格含义——参数在拟合 v4 这一段素材，换个转速/距离就失效。

### 2.3 为什么"调参"永远收敛不了

213 个参数里，只有 4 个有明确物理量纲（位置噪声、角噪声、加速度谱密度、角加速度谱密度）。
其余 200+ 个是"米""米/弧度""倍率"这类**为了在特定工况下凑出正确判定**而引入的中间量。
它们之间互相耦合（改门限就要改权重，改权重又要改 bootstrap），
所以每次调参都是在 200 维空间里找一个只在当前素材成立的局部点。

## 3. 目标架构（单一方案）

### 3.1 第一步：把身份从"打分"改成"排列"

**关键观察**：四块板在一台凸的车体上，投影/方位的**环序是物理不变的**。
所以身份不是任意的 4 选 1，而是**一个循环移位**：

```
观测按方位角排序后，第 r 个观测  一定对应  槽位 (h + r) mod 4，  h ∈ {0,1,2,3}
```

于是离散变量从"每个观测各自 4 选 1"（4^k 种组合，靠打分挑一个）
塌缩成"整帧一个循环移位 h"（**只有 4 种可能**）。

这正是 rmcs `robot.cpp:600-616` 的做法（它按图像 x 排序后 `id = id±1 mod 8`），
只是我们把排序键从"像素 x"换成"方位角"——**因此不需要像素域改造**，
tracker 层现有的 `world.position` 就够（这也回答了之前那个"要不要上像素"的问题：不需要）。

### 3.2 第二步：4 个 h 不判死，而是加权并行

对 h = 0..3 各维护一个完整假设：

```
H_h = { x_h (11 维状态), P_h (协方差), w_h (权重, Σw=1) }
```

每帧：

1. **预测**：4 份状态各自 `x ← F x`，`P ← F P Fᵀ + Q`（4×11 维，166 fps 下可忽略）；
2. **条件匹配**（确定性的，无参数）：在假设 h 下，观测按环序配对到 `(h+r) mod 4`，
   于是匹配结果**由 h 唯一决定**，不再有 argmin；
3. **更新**：每份假设用自己的配对做一次普通 EKF 更新；
4. **权重更新**：`w_h ∝ w_h · N(innovation_h; 0, S_h)`（新息似然），归一化；
5. **剪枝**：`w_h < 1e-3` 的假设并入最近邻假设，防止数值退化。

输出：

```
x_out = Σ_h w_h x_h            （混合均值，给显示/瞄准）
ω_out = Σ_h w_h x_h(7)         （转速是加权平均，不是某一个假设的瞬时值）
```

### 3.3 为什么这一改能同时解决三件事

| 现象 | 旧架构 | 新架构 |
|---|---|---|
| 槽位 41.6% 翻转 | 状态跟着跳 0.33 m | 只是权重在两份假设间迁移，**状态本身连续** |
| ω 学不上去 | 位置更新把假位移当真值 | 错配的假设新息大 → 权重迅速掉，不会污染 ω |
| 单帧 90° 不可辨 | argmin 硬判（margin p10=0.034，等于抛硬币） | **本来就该不可辨**：两份假设权重各 0.5，等时域信息来分辨 |

**单帧不可辨、时域可辨** —— 这本来就是滤波器存在的意义，现在被 argmin 强行提前判死了。

### 3.4 随之可删的补丁（架构正确性的判据）

如果新架构成立，下面这些**必须一起删掉**，否则等于新旧两套并存（更糟）：

| 类别 | 具体项 |
|---|---|
| 打分权重 | `association_angle_weight_m_per_rad`、`normal_tiebreak_weight` |
| 联合绑定 | `joint_pair_binding_enabled`、`joint_pair_binding_max_cost_m`、双板闭式解 |
| 相位开关 | `slot_phase_update_enabled`、`slot_phase_min_rate_rad_s`、`pair_phase_update_enabled` |
| 事后补救 | `single_plate_realign_m`、`single_plate_realign_gate_m`、`realign_after_misses` |
| 延迟生效 | `obs_continuity_gate_enabled`、`obs_continuity_gate_m`、`bootstrap_updates` |
| 化石 | `handoff_sigma_scale`（已标废弃）、`normal_anchor_gate_m`、`center_from_normal_gate_m` |
| 门限常数 | `position_gate_m`、`nis_gate`、`rate_associate_gate_m` → 全部改为 χ² 分位数导出 |

预期：`TrackerConfig` 从 213 → **60 以内**；bool 开关 47 → **10 以内**；env 46 → **只留 A/B 用的 6~8 个**。

## 4. 统一的调参行为控制

架构落地后，参数只允许出现三档：

### 4.1 物理参数（唯一需要人工给定的）

| 参数 | 量纲 | 说明 |
|---|---|---|
| `sigma_position_m` | m | 由重投影误差换算（已有机制，保留） |
| `sigma_yaw_rad` | rad | 只在用相位量测时出现 |
| `q_accel` | (m/s²)²/Hz | 平移过程噪声 |
| `q_angular_accel` | (rad/s²)²/Hz | 转速过程噪声 —— **只此一个旋钮管"转速能变多快"** |
| `p0_*` | 各自量纲 | 由首帧量测协方差导出，不手填 |

### 4.2 统计参数（由噪声导出，不许手调）

- 门限：`χ²(0.997, dim)`；
- 假设剪枝：`w < 1e-3`；
- 权重更新：标准贝叶斯，无温度、无偏置。

### 4.3 实验开关（只许是 A/B，不许改行为语义）

- 环境变量只用于 `A/B 对照` 与 `诊断输出`（`ASSOC_DEBUG`、`SIZE_DEBUG` 这类）；
- **任何能改变滤波行为的量都不许走 env**，必须走 `config/*.yaml` 单一入口，
  且带量纲注释。这一条是对"46 个 env 变量"的直接反制。

## 6. 不做什么（明确划线）

1. **不上像素域**：环序配对用方位角就够（§3.1），像素域是 400~600 行的层边界改造，收益重叠。
2. **不把 `EKF_SPHERICAL` 打开**：4 维球坐标量测历史实测"会把瞄准点打到相邻板上"，
   本质是同一身份问题的另一种表现；S2 之后它才有意义，届时单独评估。
3. **不动检测层**：D1 今日已确认在 v4/v1 上零命中。
4. **不动 Q 的量级**：`SPIN_Q`/自适应已在，S2 之后 ω 有观测支撑再统一收敛到 §4.1。

## 8. S0 + S1 实测结论（2026-10-25，已执行）

### 8.1 S0：诊断口径已修

`test_camera_playback --dump` 末尾新增 8 列（追加，不动原有列序）：

```
tyaw, thasyaw, tslot, ringk, rc0, rc1, rc2, rc3
```

`tyaw` = tracker 内部 `WorldObservation.yaw`（已过符号守卫），`oyaw` 仍是 StudentTasks 原始位姿。
两者在 78% 的行上完全一致；其余 22% 是"该行观测不是本帧被选中的那一块"（多板帧），
最大差 119°（不是 180°）——说明**法向符号守卫在实拍上确实不触发**，与 §4 的判断一致。

### 8.2 S1：4 个假设能否分开——**能，而且很干净**

`RING_DEBUG=1` 在 v4（`--only-id 3`）上跑，954 行 dump 中：

| 项 | 值 |
|---|---|
| `ringk ≥ 2`（多板帧，方案真正生效的场合） | **418 帧** |
| `ringk == 1`（单板帧，4 个 h 同构，不启用） | 533 帧 |

**可分性（418 个多板帧）：**

| 指标 | p10 | p50 | p90 |
|---|---|---|---|
| 绝对 margin（次优代价 − 最优代价） | 3.81 | **14.40** | 52.11 |
| 相对 margin（次优/最优 − 1） | 0.10 | **0.65** | 1.61 |

`margin < 0.1` 的帧数：**0**。即最优假设的代价中位比次优低 **65%**，不存在"两个 h 打平"的帧。

**时域稳定性（相邻多板帧最优 h 的变化量）：**

| 变化量 | 次数 | 含义 |
|---|---|---|
| 0 | **362**（86.8%） | 配对不变 |
| 1 / 3 | 45 / 9 | 有板进出视场，锚点滑动一格 |
| **2（180°）** | **1** | 唯一一次跳两步 |

对照：当前 argmin 的槽位序列变化率是 **41.6%**。环序配对把"身份翻转"从每 2.4 帧一次压到 **1/418**。

**配对质量：** 最优 h 的等效逐点残差（按 σ=0.03 m 折算）p50 = **11.0 cm**、p90 = 16.7 cm。
约为 0.5R —— 说明模型相位仍不精确（ω≈0 的必然结果），
**但 4 个假设是"同一模型下比较"，这个偏差会被差分掉**，不影响可分性；
同时它意味着权重不会退化成一个尖峰，不确定性被如实保留——这正是多假设该有的行为。

### 8.3 结论

**S1 通过，S2 可以开工。** 判据：

1. 4 个假设可分（相对 margin p50 0.65、无打平帧）→ 高斯和不会退化成"平均成一个糊状解"；
2. 最优 h 时域稳定（86.8% 不变、±2 只有 1 次）→ 权重会在时域上保持主次，不会每帧乱跳；
3. 单板帧占 533/954（56%），且单板路径本来就是好的（34°/0.2%）→ **S2 必须保留单板旁路**，
   这也是 S2 的硬门槛。

## 9. S2 实施后的修订（2026-10-25，详见 `docs/身份后验-从环序假设到精确枚举_2026-10-25.md`）

§3.2 的「4 个 h 各持一份完整状态、加权融合」**已被实测否决**，两处修订：

1. **多假设作用在「配对」上，不作用在「状态」上**。h 不改变演化方程，4 份状态只会沿
   90° 规范自由度漂开（板位置集合相同、θ0 差 90°），加权平均无意义；且整体替换
   `ekf_` 会让窗口转速 / body_refit / 半径慢通道 / 掉线快照全部失锚
   （实测可运行帧数 1113 → 937）。最终形态：**单一状态 + 身份后验**，
   结论以 `forced_slot` 喂回原链路。
2. **假设集从「4 个循环移位」扩到「全部单射配对」**。环序的物理前提（同帧可见板在
   槽位上连续）被 §1 的位移直方图否掉——2R（对置板）也有峰。而 N=4、k≤4 时
   全部单射配对只有 12/24/24 种，小到可以穷举，没有理由再用几何近似。

顺带修正 §5 的验收判据：「槽位翻转率 41.6% → <5%」是**无效指标**：`tslot` 是
「本帧被选中那块板的槽位」，两块板都可见时会随「哪块更近」自然交替，
与身份判对判错无关。§8.2 里那个 41.6% 同样受此污染。有效判据只有下游量
（瞄准板残差 / ≤5cm / |ω| / R）。
