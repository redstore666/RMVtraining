## 2. 已经做完、有数据支撑的结论

- **v4「圆心偏」的根因**：① 目标在两台车之间反复切换（迟滞 0.10 → 0.30 后切换 0 次、
  命中中位 5.9 cm → 0.68 cm）；② 法向在 ±45° 折叠边界翻面，逐帧微分给出 16 rad/s 假转速
  （改成 0.35 s 窗口 Theil-Sen + 换板续接 + 双路证据 + 无证据衰减后 omega ∈ [−0.14, +0.23]）；
  ③ 单板锁定时半径被噪声带偏（加板型先验护栏）。
- **v1「镜头晃动被当旋转」**：修前 omega 发散到 10 rad/s，修后 |omega| ≲ 0.6、mode=static。
  只给图像不给 IMU 时"手持晃"和"目标自转"在世界系里不可分，剩下的 8 cm 是抖动地板
  （`--phase-yaw`、`--q-scale` 都验证过不是杠杆）。
- **多目标**：`MultiTargetTracker` 用径向一致性 `| |p−c| − R |` 分组，v4 全量累计新建 2 辆
  （静止大板 + 在动小板），`--multi` 时俯视图主车亮色、其它车灰紫。新增回归测试
  `test_multi_target`（ctest: `ekf_multi_target`）。

## 6. 环境注意事项

- 本沙箱**每次 bash 调用有独立 /tmp**，产物要写在仓库目录下（`build/...`），否则下一次调用看不到。
- 改过 `CMakeLists.txt` 新增 target 后，必须先 `cmake -S . -B build` 再 build，否则报
  `No rule to make target`。
- 有 `DISPLAY=:0` / `WAYLAND_DISPLAY=wayland-0` 时可开窗口（`--topdown`、`test_ekf_viewer`）；
  无显示时用 `--no-show --out DIR` 逐帧导 PNG。
- 提交前若 `MvSdkLog/CamCtrl_00.log` 被相机测试写脏，用 `git checkout -- MvSdkLog/CamCtrl_00.log` 还原。
