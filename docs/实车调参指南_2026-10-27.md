# 实车调参指南（上车最小版，2026-10-27）

> 架构已冻结：所有验证失败的默认关闭路径（球坐标量测、批拟合、整车重拟合、PLL、
> 圆相位、法向相位、槽位相位、body_circle、tracklet 联合解、观测平滑、法向量测、
> 快照续接、声明反驳、槽位偏移学习、重锚以外的全部硬写通道）已从代码中删除。
> **上车只调 Q/P，不改任何分支逻辑。**

## 0. 调参总原则

1. **一次只动一个参数**，动完跑同一段回放素材对比三指标：预测命中中位 / ≤5cm 占比 / 瞄准板残差中位。
2. 先在回放工具上扫，再上车：`test_camera_playback` 的 `--q-scale` 直接映射 `process_accel_scale`。
3. 方向感：**Q 大 → 跟得紧但抖；Q 小 → 平滑但滞后**。R 大 → 信观测；R 小 → 信模型。

## 1. Q（过程噪声）—— 3 个旋钮

### 1.1 `process_accel_scale`（全局 Q 倍率，回放 `--q-scale`）

位置：`TrackerConfig::process_accel_scale`，默认 **1.0**。
生效：`accel_x = accel_y = accel_z = 0.01 × scale`（applyProcessNoise）。
它同时乘到角加速度通道（见 1.2 的公式），所以是"整车机动性"总旋钮。

| 症状 | 方向 |
|---|---|
| 车心/瞄准点跟不上加减速 | 调大（1.0 → 1.5 → 2.0） |
| 静止观察时车心/瞄准点抖 | 调小（1.0 → 0.7 → 0.5） |

### 1.2 `process_angular_accel`（转速通道专用 q，默认 **4.0**）

位置：`TrackerConfig::process_angular_accel`。生效：`Q_ω = q · dt`（连续白噪声谱密度）。
注意它与 1.1 相乘：最终 `angular_accel = process_accel_scale × process_angular_accel`。

量纲对照（166 fps）：sp_vision_25 的 `v2=400` ⇔ 本项目 `q≈2.4`；我们因单帧噪声更大取 4.0。

| 症状 | 方向 |
|---|---|
| ω 估计落后真实转速（模型板跟不上旋转） | 4.0 → 6.0 → 8.0（8 以上会打崩 v1 类素材） |
| ω 抖动 / ±10 方波 / 静止车被读出转速 | 4.0 → 2.5 → 2.0 |

配套闸门（一般不动，动 Q 无效时才看）：
`rate_max_sigma_rad_s`（6.0，窗口斜率标准误上限）、`rate_max_abs_rad_s`（12.0，物理闸门）、
`rate_decay_after_s` / `rate_decay_sigma_rad_s`（0.60s 无证据后把 ω 拉回 0）。

### 1.3 机动自适应放大（默认开，通常不调）

`ekf.adaptive_process_noise=true`：NIS 超过 `adaptive_nis_floor`（9.0）时按
`adaptive_alpha`（0.35）EMA 抬高速度/角速度的 Q（上限 `adaptive_scale_max`=80），
平稳时按 `adaptive_decay`（0.990）回落。**它放大的是 1.1/1.2 的效果**——如果
1.1/1.2 怎么调都不对劲，先把它关掉（置 false）排除交互再扫。

## 2. P（量测噪声与初值）

### 2.1 `position_sigma_m`（默认 **0.03 m**）—— P 的基础

R 的基础尺度，之后按重投影质量缩放（`position_sigma_quality_gain/floor`），
再与自适应噪声（2.3）取 hypot。检测离车更近/更清晰时可降到 0.02。

### 2.2 `association_sigma_floor_m`（默认 **0.06 m**）—— NIS 地板

模型误差兜底。**全拒跟（NIS 门把所有帧拒掉、锁定后 0 更新）时调大**（0.06 → 0.08）；
更新变钝（残差追不上观测）时调小。回放 `--sigma-floor` 可扫。

### 2.3 观测噪声自适应（默认开）

`adaptive_observation_noise=true`：按连续帧二阶差分估当前抖动，
夹在 `adaptive_noise_min_sigma_m`(0.004) 与 `adaptive_noise_max_sigma_m`(0.090) 之间。
抖动大的场地把 max 放大点（0.09 → 0.12）；怀疑它作怪时 `--adaptive-noise 0` 关掉对比。

### 2.4 `angle_state_sigma_rad`（默认 **0.31 rad**）—— 角度量测通道强度

参考实现刻度（17°），`angle_state_obliquity_sigma=true` 时按斜视角公式自动覆盖。
**与 identity_posterior_enabled 耦合**：槽位判错 = ±90° 硬拽，身份后验必须同时开（默认已开）。
旋转目标相位抖 → 调大（0.31 → 0.5）；相位滞后 → 调小（0.31 → 0.2，注意配合身份后验）。

### 2.5 P0 初值（tryLock 内，代码常量，一般不动）

`yaw_sigma=0.63`（=PnP 法向实测噪声）、`yaw_rate_sigma=clamp(2×slope_error, 1, 10)`、
`position_sigma=0.15`。锁定后前 `bootstrap_updates`(10) 帧放宽 NIS 门让 P0 收敛。

### 2.6 `velocity_sigma_m_s`（默认 **0.05 m/s**）—— 平动速度先验

压得很小 = 基本钉死"车心慢动"。**纯平移目标如果车心追不上** → 调大（0.05 → 0.2 → 0.5）；
旋转目标如果平移被解释成旋转（车心飞） → 调小或保持 0.05。

## 3. 上车调参顺序（建议）

1. **先定 R 通道**：确认锁定半径与实车一致（`radius_prior_small/large_m` 或回放 `--radius`）。
   半径错了后面全白调。半径收敛后 `freeze_radius` 自动锁死，无需干预。
2. **再调 Q_ω**（1.2）：拿旋转素材回放，看 ω 估计 vs 真值（诊断里 `locked_spin_rad_s` / web 面板）。
3. **再调 q-scale**（1.1）：拿平移+加减速素材，看车心滞后 vs 抖动。
4. **最后微调地板**（2.2/2.3）：只在上车后如果出现"全拒跟"或"更新变钝"时动。

每步的离线验证命令：

```bash
# 旋转素材（看 ω 通道）
./build/test_camera_playback tests/resources/redrotate.avi --red --ekf --headless
# 平移素材（看车心通道）
./build/test_camera_playback tests/resources/bluemove.avi --blue --ekf --headless
# Q 扫参：--q-scale 0.5 / 1.0 / 1.5 / 2.0 各跑一遍对比"EKF 汇总"三行
# Q_ω 扫参（不改编译）：SPIN_Q=6 ./build/test_camera_playback ...（angular_accel = 0.01×SPIN_Q×scale）
```
