## 第 15–16 轮：定位到"转一部分卡回去"的确切机制

### 已确认事实（都是实测，不是推测）

1. **PIX 只在 `pose.detection.target_id == diagnostics.target_id` 时统计**
   （tests/test_camera_playback.cpp:1470-1474）。所以 776 个 id=3 样本对应的是
   滤波器确实在跟踪 3 号的那些帧，不存在"用 1 号状态去比 3 号观测"。

2. **yaw 单帧跳 140°–215°**，这就是"转一部分然后卡回去"：

   ```
   f=199  R=0.337  yaw=-1.62  ok=44
   f=200  R=0.323  yaw=+2.13  ok=45   <- 跳 +3.75 rad
   f=224  R=0.296  yaw=+2.77  ok=57
   f=225  R=0.294  yaw=-0.99  ok=58   <- 跳 -3.76 rad
   f=242  R=0.289  yaw=-0.47
   f=243  R=0.289  yaw=+1.98  ok=79   <- 跳 +2.45 rad
   ```

   每次跳变都伴随一次被接受的更新（ok 加 1）。

3. **几何本身是自洽的**，不是半径错：同帧双板间距 209 帧中位 0.405 m
   （p10 0.385 / p90 0.431），反推 R = 0.286，而滤波器 R 在 0.288~0.317 之间。
   f=197 的 chord=0.503 是唯一离群（R=0.356）。

4. **位置门限扫描全部无效**：gate 从 0.60 收到 0.10，id=3 始终 776 帧一帧不拒，
   PIX 反而从 103.2 涨到 127.9。原因是滤波器预测跟着观测走，门限拦不到东西。

### 根因：位置更新与相位更新在"哪个槽位"上互相打架

`RotatingArmorEkf::updatePhase`（student/src/RotatingArmorEkf.cpp:265）：

```cpp
const double period = 2.0 * kPi / static_cast<double>(config_.plate_count);
const double residual = foldPeriod(state_(6) - measured_world_yaw, period);
```

相位更新把残差折叠到 ±45°（period = 90°），**它从来不改变"哪块板是 slot 0"
这个判断**，只修正 45° 以内的抖动。而位置更新**没有这个折叠**，可以把 yaw 推过
45° 的边界，导致槽位翻转。两者永远无法达成一致——这正是
student/include/RotatingArmorTracker.hpp:180-183 注释里写的：

> 默认关闭：合成 A 场景实测"打开后 yaw 抖动、半径被压到 0.18（真值 0.25）"，
> 因为位置更新与相位更新在"哪个槽位"这件事上互相拉扯。能力保留、单测覆盖
> RotatingArmorEkf::updatePhase 本身；等有"按槽位一致"的写法再默认打开。

配置现状（student/include/RotatingArmorTracker.hpp）：

```cpp
bool phase_update_enabled{false};      // 182 行
bool phase_update_when_static{true};   // 187 行，但要求 |omega| < static_rate
```

旋转目标上两个条件都不成立，于是 **yaw 完全靠位置观测**，而双板位置观测对
yaw 有 90° 相位模糊，yaw 就在两个解之间反复跳。

### 试过并否定

- `--phase-yaw`（打开 `phase_update_enabled`）：id=1 样本 516 -> 303（变差），
  id=3 103.2 -> 108.1。印证了注释里的"打开后互相拉扯"。

### 下一步：按槽位一致的相位更新

1. 给 `updatePhase` 增加槽位参数：`updatePhase(measured_world_yaw, sigma, slot)`，
   用 `target_yaw = measured_world_yaw + slot * period` 作为目标，**不做折叠**，
   这样它能把 yaw 从 45° 以外拉回来，真正锁住槽位分配。
2. 双板帧里两块板**共同**确定槽位分配（而不是各自贪心），再用同一分配做
   位置更新 + 相位更新。
3. 静止车不能退化：`phase_update_when_static` 的单板路径要保持现状
   （id=1 的 2.3 px 必须不变）。
